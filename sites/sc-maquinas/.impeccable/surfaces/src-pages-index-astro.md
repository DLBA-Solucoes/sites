## Scope

Whole marketing site for SC Máquinas (home, máquinas index, product pages, culturas, sobre/fábrica, blog, contato) in pt, en, es. Mode: Persuade (home, sobre), Read-leaning (product sheets).

Audience: rural producer on phone; dealers and export buyers secondary. Action: find the right machine by crop + tractor HP + hitch, then call or email SC. Proof: real studio shots, drone field photos, factory, spec tables, PDFs, 1995-2023 history. No testimonials exist; none invented.

## Direction contract

THESIS: The site is the printed catalog handed across SC's stand at an agro fair: each machine lit on a black stage, its model code set huge, parts numbered into the spec sheet. It refuses the category default of a green-field hero with "tradição e qualidade" over a row of equal product cards.

OWN-WORLD: Stage graphite #111315 owns most surfaces; steel #2a2e33 for rules and panels; spec sheets are inserted paper pages (#f4f4f1) with ink #111315; SC navy #1d2a5c as the paper sheets' structural colour; SC red #d7262e is the single action colour. Archivo variable: condensed heavy for model codes and headlines, normal width for body, tabular numerals in specs. Hard square corners, 1px steel rules, numbered index markers Nº 01-18.

STORY: Visitor sees SC builds real machines in its own factory, finds models that fit their crop and tractor in one move, reads a comparable spec sheet, and calls or emails.

FIRST VIEWPORT: Black stage. Huge ghost model code behind a large studio cutout of the AT-1000 atomizer filling the right 60%, crossing the fold. Left: headline (condensed, uppercase, 2-3 lines) and one short lead. Bottom band: working finder on paper (Cultura select, Trator HP select, Engate toggle) with a red "Ver N máquinas" button that live-updates its count. Phone number in the header.

FORM: Catálogo de Feira (agro-fair implement catalog), position 3 of my ordered list. seed:c6bb4b5f556254b9. Raises: fixed-slot spec sheets with ghost dashes (from seven-segment); one continuous custody line 1995-2023 (provenance ribbon); field photos as numbered frames with real edge codes crop · model (16mm); Nº index as catalog navigation (j-card); one orchestrated entrance clock, no scattered hover (algorave); unframed hard-edged field photos (décollage).

Signature interaction: the finder filters the catalog live with count; numbered callouts on hero machine link to spec rows.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
